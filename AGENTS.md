# Работа с SQL

- SQL проверяется через `python tools/jsql.py` (см. tools/README.md). Платформа доступна только с этого компьютера.
- Цикл на гипотезу: написать `sql/explore/<кейс>_<шаг>.sql` с `-- check:` → `run` → разобрать вывод → исправить → повторять, пока все проверки OK и цифры правдоподобны. Человека звать только при неоднозначности в постановке или если данных нет.
- Перед JOIN проверять grain и уникальность ключей (`unique(...)`), после JOIN сверять число строк.
- Таблицы: `lakehouse.raw.pg__*`, `lakehouse.raw.mongo__*`; писать в `stage`/`mart` только через пайплайн Портала.
- Анонимный `account_id = 4294967295` исключать из метрик по игрокам.
- Источники чистятся каждые 4 часа, история есть только в RAW.
- Не выводить содержимое `.env`, не печатать токены и DSN. `SOURCE_*` переменные читать только через `os.getenv` в ядре.
- Коммиты без упоминаний ИИ.
