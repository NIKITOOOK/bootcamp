## Макет по блокам

**Верхняя полоса, 4 показателя (Big Number):**
1. Матчей в анализе (`count` из `stage.t1_c13_matches`).
2. Героев с достаточной выборкой (`games` ≥ порога).
3. Доля побед при 3+ упавших башнях к 15-й минуте (ds_push).
4. Время последней загрузки (`max(loaded_at)`).

**Фильтры (общие, работают по колонкам витрин):** позиция 1–5, тип здания, окно времени, число пушеров в команде, фаза матча.

**H1. Часть героев бьёт здания сильнее ожидаемого**
- Столбчатая диаграмма: топ-15 героев по `tdpm_index`, линия 1,0 = норма позиции (ds_hero).
- Тепловая карта «герой × позиция» по `tdpm_index`.

**H2. Эффект способности зависит от здания и стадии**
- Столбцы: средний урон за удар `ratio_to_t3` по типам T1, T2, T3, T4, бараки, трон; серия «физический урон» и серия «способности» (ds_ability).
- Столбцы по стадиям: `dmg_per_exposure_min` в окнах 0–10, 10–15, 15–30, 30+.
- Таблица: топ способностей (источник, уровень, `hits`, `dmg_per_hit`, `matches`), строки с малым `matches` скрыты.

**H3. Ранний пуш и победа**
- H3a: доля побед по числу упавших башен соперника к 15-й минуте (0, 1, 2, 3, 4+), подпись числа матчей (ds_push).
- H3b: доля побед по башням внутри групп золота (ниже и выше среднего). Если столбцы выровнялись, пуш работает через золото.

**Нижняя полоса:** вердикты H1, H2, H3a, H3b одной строкой; ограничения (позиция по `net_worth`, анонимные игроки 32%, покрытие `building_events` 25%, выборка и один патч, связь не причина); ссылки на ноутбук и схему lineage.
