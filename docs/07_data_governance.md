## SLA и актуальность

- RAW обновляется **раз в 2 часа**, один прогон RAW занимает около 1 часа. Поэтому свежесть данных в RAW составляет около 3 часов.
- STAGE и MART стартуют по датасетам после обновления входов; к 3 часам добавляется время цепочки (замерить по Airflow DAG Runs, planned).
- Целевой SLA витрин: данные не старше 4 часов относительно момента появления матча в источнике (3 часа RAW + цепочка потоков). Для защиты критична готовность к 10:00 15.11.
- Встроенного SLA в Airflow нет, паспорт — наш документ.
- При падении потока остаётся прошлая версия таблицы (коммит Iceberg атомарный), время последней загрузки показываем на дашборде.

## Каталог метрик

| Метрика | Определение |
|---|---|
| `tdpm` | урон по зданиям в минуту: `tower_damage × 60 / duration_sec` |
| `tdpm_index` | медиана `tdpm` героя на позиции / медиана `tdpm` всех героев на этой позиции |
| `pos_proxy` | место по `net_worth` в команде (1–5), приближение позиции |
| `win_rate` | сумма побед / число игр |
| `towers_down_15` | число башен соперника, упавших до 900-й секунды |
| `bld_dmg_15` | урон команды по зданиям до 15-й минуты |
| `gold_15` | суммарное золото команды до 15-й минуты |
| `exposure_sec` | сколько секунд здание данного типа стояло в окне |
| `ratio_to_t3` | урон за удар по зданию / урон за удар по T3 того же источника |

## Lineage

Платформа отправляет события в Marquez через `lineage_outbox_relay` (примерно раз в 10 минут), пространства имён `lakehouse_raw`, `lakehouse_stage`, `lakehouse_mart`.

| Объект | Входы | Потребители |
|---|---|---|
| stage.t1_c13_matches | raw.pg__matches, raw.pg__match_players | players, building_falls, tower_hits, team_early_push |
| stage.t1_c13_players | raw.pg__match_players, raw.pg__heroes, raw.mongo__purchase_events, stage matches | hero_tower_damage, tower_hits, team_early_push |
| stage.t1_c13_building_falls | raw.mongo__tower_death_events, raw.mongo__building_events, stage matches | ability_building_damage, team_early_push |
| stage.t1_c13_tower_hits | raw.mongo__tower_damage_events, raw.mongo__ability_learn_events, raw.pg__npcs, abilities, items, stage matches, players | ability_building_damage, team_early_push |
| mart.t1_c13_hero_tower_damage | stage players | Superset: рейтинг героев (H1) |
| mart.t1_c13_ability_building_damage | stage tower_hits, building_falls, matches | Superset: лестница по зданиям (H2) |
| mart.t1_c13_team_early_push | stage tower_hits, building_falls, players, matches, raw.mongo__gold_events | Superset: ранний пуш и победа (H3) |

Superset в Marquez автоматически не попадает: связь «витрина → график» показываем схемой. Граф Marquez снимается после запуска всех потоков (planned).

## Персональные данные и безопасность

ПДн в кейсе нет. `account_id` используется только как ключ соединения и для флага `is_anonymous`, в STAGE и MART не выводится. Пароли и токены не хранятся ни в ноутбуках, ни в репозитории, ни в документах.

## Порядок изменений

Поток нельзя редактировать, только удалить и создать заново, и только если от него никто не зависит. Поэтому SQL сначала проверяем предпросмотром и в ноутбуке.
