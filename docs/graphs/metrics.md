# Кейс 13. Способности и герои: урон по зданиям

Команда 1 · буткэмп Dota 2 · lakehouse (Trino, каталог `lakehouse`)

## 1. Цель

Понять, какие герои и способности дают непропорционально большой вклад в урон по зданиям (башни, бараки, трон),
как этот вклад зависит от стадии игры и типа здания, и связан ли ранний урон по зданиям с победой.
Ноутбук — прототип: SELECT-запросы раздела 9 потом станут STAGE/MART-потоками Портала.

<!-- cell 1 -->
## 2. Бизнес-вопрос

Текст кейса на Портале (#13 «Способности по башням», категория «1 - Простые»):

> Сравнить вклад героев и способностей в урон по башням. Свяжите способности и героев с уроном по башням,
> контролируя время появления объекта и состав команды.

Связь с главным вопросом буткэмпа («что связано с победой»): урон по зданиям — прямой путь к победе
(трон — условие конца матча), поэтому проверяем, переводится ли ранний пуш в победу (H3).

## 3. Гипотезы

| # | Если … | то … | потому что … | Данные | Метрика | Проверка |
|---|---|---|---|---|---|---|
| H1 | герой — «пушер» (сильные призывы, урон способностями по зданиям) | его урон по зданиям выше ожидаемого для его позиции, даже при контроле состава команды | у таких героев урон по зданиям не зависит от фарма | `pg__match_players`, `mongo__tower_damage_events`, `mongo__purchase_events` | индекс TDPM = Σ TDPM героя / Σ среднего TDPM его позиций; σ = доля в уроне команды; урон на секунду доступности здания | Mann–Whitney + BH, bootstrap-ДИ индекса, OLS log(1+TDPM) с контролями и кластерными ошибками по матчу |
| H2 | источник урона физический (атака, призывы) | урон за удар сильнее падает на «бронированных» зданиях (T4, трон), чем у магии | у зданий разная броня, магия её игнорирует | `mongo__tower_damage_events`, `pg__abilities`, `mongo__ability_learn_events` | средний урон за удар источник × тип здания × окно; κ Nether Blast | WLS log(урон за удар) ~ источник × тип + окно, F-тест взаимодействия |
| H3 | команда снесла больше башен / нанесла больше урона по зданиям к 15 мин | её шанс победы выше при равном золоте и составе | ранние башни дают золото, карту и давление | `mongo__tower_death_events`, `mongo__tower_damage_events`, `mongo__gold_events` | доля побед, коэффициенты логита | логит win ~ Δбашни15 + Δурон15 + Δзолото15 + Δсостав, AUC |

## 7. Предобработка

* фильтр матчей: `game_mode <> 23`, `duration >= 900`, выборка `match_id % 20 = 0`;
* позиция-прокси: ранг игрока по net_worth внутри команды (1 — самый богатый);
* TDPM = tower_damage × 60 / duration;
* тип здания по npc_id: T1–T4, rax_melee, rax_range, fort (fillers отдельно);
* источник урона (правило): `hero_attack` — нет byability/byitem/fromnpc; `ability` — byability > 0 без юнита;
  `item` — byitem > 0 или юнит Necronomicon; `own_summon` — призыв героя (варды, forged spirit, treant, скелеты, медведь …,
  а также нейтралы у Chen и Enchantress); `helm_unit` — нейтрал под Helm у остальных героев; `other_npc` — лайн-крипы и прочее.

### Интерпретация вердиктов

* **H1 — подтверждена.** 43 из 126 героев значимо выше ожидаемого для своей позиции (Mann–Whitney + BH, нижняя граница 95% ДИ индекса > 1). Лидеры: Pugna 3,05, Visage 2,97, Shadow Shaman 2,65, Broodmother 2,24, Lycan 1,83. В регрессии с контролями (R² 0,64) эффекты сохраняются: Pugna ×4,3, Visage ×4,3, Broodmother ×4,2 к среднему герою. Каждый сильный пушер-союзник снижает TDPM героя примерно на 5,5%, σ падает 0,26 → 0,19 → 0,14 (0 / 1 / 2+ союзника).
* **H2 — подтверждена.** Взаимодействия источник × тип здания и источник × окно значимы (F = 11,7, p ≈ 1e-18, 124 клетки). Физический урон: T4/T3 = 0,80 при одинаковом окне; магия (Nether Blast) не теряет на T4: T4/T3 = 1,05. κ Nether Blast на уровнях 1–3 = 0,653 (множитель 0,65 по зданиям), на 4 уровне растёт к трону до 0,80.
* **H3 — подтверждена частично.** Без контроля золота связь сильная: доля побед 34% / 51% / 64% / 77% / 90% при 0 / 1 / 2 / 3 / 4+ снесённых башнях врага к 15 мин (AUC 0,70). Но золото к 15 мин объясняет почти всё: AUC модели только с золотом 0,789, с пушем и составом 0,790. При равном золоте разница урона по зданиям к 15 мин ещё связана с победой (OR 1,10 на 1000 урона, p = 0,004), а разница башен меняет знак (OR 0,87, p < 0,001) — башни уже учтены в золоте (коллинеарность). Состав команды (сильные пушеры, Helm) при этом не значим. Вывод: ранний пуш связан с победой в основном через экономическое преимущество.
